# Prague AI Talk 2026

Welcome to the Prague AI Talk 2026 hands-on practice session!

## Hands-on Practice (20 minutes)

This repository contains 4 practice activities to explore different AI tools and capabilities.

### Practice Activities

1. **[Gumploop Workflow](./1-Gumploop-Workflow/)** - Create an automated email digest workflow
   - Task: Create an email digest every Monday with top news using Perplexity as the news source

2. **[NotebookLM](./2-NotebookLM/)** - AI-powered note-taking and research
   - Task: Work with Transcarent links to generate summaries and insights

3. **[Microsoft Office](./3-Microsoft-Office/)** - AI features in OneDrive
   - Task: Ask questions about documents and get AI-generated summaries

4. **[Image Redesign](./4-Image-Redesign/)** - AI image transformation
   - Task: Redesign images and combine multiple images into one

### Getting Started

1. Choose one or more activities that interest you
2. Navigate to the activity folder
3. Follow the instructions in each folder's README
4. Try the prompts with your choice of AI tool/model

### Duration
20 minutes total - feel free to explore one activity in depth or try multiple!
