# Prague AI Talk 2026

Welcome to the Prague AI Talk 2026 hands-on practice session!

## Overview

This repository contains 4 practice activities designed to help you explore different AI tools and capabilities. Each activity includes sample files and detailed instructions to get you started quickly.

![cat-prague.jpg](assets/cat-prague.jpg)

## Hands-on Practice Activities (20 minutes)

### 1. [NotebookLM](./2-NotebookLM/) - AI-Powered Research Assistant
**What you'll do:** Analyze web content and generate AI-powered insights about Transcarent company

**Key Features:**
- Upload web URLs and let AI synthesize information
- Generate podcast-style audio overviews from written content
- Ask questions and get answers with source citations
- Create study guides, summaries, and mind maps

**Platform:** [Google NotebookLM](https://notebooklm.google.com/) (Free)

**Files included:**
- `transcarent-links.txt` - 49 curated Transcarent company URLs ready to analyze

---

### 2. [Microsoft Office](./3-Microsoft-Office/) - M365 Copilot Document Analysis
**What you'll do:** Use AI to analyze and extract insights from business documents

**Key Features:**
- Ask natural language questions about your documents
- Extract action items, decisions, and deadlines automatically
- Analyze spreadsheet data without writing formulas
- Generate summaries and compare documents

**Platform:** [Microsoft 365 Copilot](https://m365.cloud.microsoft/chat)

**Files included (3 ready-to-use samples):**
- `AI-Strategy-Meeting-Notes-2026-01-10.docx` - Meeting notes with 7 action items, 5 key decisions, multiple stakeholders and deadlines
- `AI-Adoption-Impact-Report-Q4-2025.docx` - 15-page comprehensive business report with executive summary, financial analysis (€2.3M savings, 259% ROI), and strategic recommendations
- `AI-Tool-Usage-Analytics-Q4-2025.xlsx` - Multi-sheet Excel workbook with team performance metrics, cost analysis, user survey results (100 responses), and monthly trends

---

### 3. [Image Redesign](./4-Image-Redesign/) - AI Image Transformation
**What you'll do:** Redesign and reimagine a kitchen using free AI image generation tools

**Key Features:**
- Transform images using different design styles (modern, rustic, futuristic, etc.)
- Experiment with various AI image generation prompts
- Compare results from different AI tools (ChatGPT, Gemini)
- Learn prompt engineering for image generation

**Platforms:**
- [ChatGPT](https://chatgpt.com/) (Free)
- [Google Gemini](https://gemini.google.com) (Free)

**Files included:**
- `kitchen.jpg` - Sample kitchen image ready for creative redesign

---

### 4. [Gumploop Workflow](./1-Gumploop-Workflow/) - No-Code AI Automation
**What you'll do:** Create an automated email digest workflow using natural language

**Key Features:**
- Build workflows by describing what you want in plain English
- Combine Perplexity AI for news gathering with Claude Haiku 4.5 for processing
- Set up automated weekly email digests for any topic you choose
- No coding required - just paste a prompt and Gumploop builds the workflow

**Platform:** [Gumloop](https://www.gumloop.com/pipeline) (Free tier available)

**Files:** No files needed - create directly in Gumploop platform

---

## Getting Started

1. **Choose your activity** - Pick one that interests you (or try multiple!)
2. **Navigate to the folder** - Each activity has its own detailed README with step-by-step instructions
3. **Access the platform** - All tools offer free tiers or trials
4. **Follow the prompts** - Each README includes specific prompts to try
5. **Experiment** - Feel free to modify prompts and explore

## What You'll Learn

- **Gumploop:** No-code workflow automation using AI
- **NotebookLM:** Research synthesis and audio generation from web sources
- **Microsoft 365 Copilot:** Enterprise document analysis and Q&A
- **AI Image Tools:** Creative image transformation and prompt engineering

## Time Management

**Total time: 20 minutes**

Suggested approaches:
- **Deep dive:** Spend 20 minutes on one activity to fully explore its capabilities
- **Survey:** Try 2-3 activities for 5-7 minutes each to compare different tools
- **Focused:** Pick the activity most relevant to your work
