# Microsoft Office AI Features

## Practice Activity

Explore AI capabilities in Microsoft Office with OneDrive integration.

### Task
Open OneDrive and use AI to ask questions about your documents and get summaries.

### Steps to Try

1. Access OneDrive (https://onedrive.live.com/)
2. Select any document in your OneDrive
3. Use Microsoft Copilot or AI features to:
   - Ask questions about the document content
   - Request a summary of the document
   - Generate insights or key points
   - Ask for specific information within the document

### Example Prompts
- "Summarize this document"
- "What are the key points in this file?"
- "Find information about [specific topic]"
- "What action items are mentioned?"

### Expected Outcome
AI-powered document understanding and intelligent responses to queries about your OneDrive files.

**Time Allocated**: Part of 20-minute hands-on practice session
