# Gumploop Workflow - Email Digest Automation

## Practice Activity

Create an automated workflow using Gumploop to generate weekly email digests.

### Task
Create an email digest every Monday with top news for the past week using Perplexity as the source of news.

### Steps to Try

1. Access Gumploop platform
2. Create a new workflow
3. Use the following prompt:
   ```
   Create an email digest every Monday, to with top news for the past week. 
   Use Perplexity as the source of news.
   ```
4. Configure the workflow:
   - Set schedule: Every Monday
   - Connect Perplexity as news source
   - Set up email delivery
5. Test and deploy your workflow

### Expected Outcome
An automated workflow that sends weekly news digests every Monday using AI-curated content from Perplexity.

**Time Allocated**: Part of 20-minute hands-on practice session
