# Sample Images for AI Image Redesign

This folder contains sample images for the hands-on practice session.

## Available Images

**Note**: Add your sample images to this folder before the session.

### Recommended Image Types

1. **sample-image-1** - Architecture or building photo
2. **sample-image-2** - Nature or landscape photo  
3. **sample-image-3** - Product or object photo
4. **sample-image-4** - Portrait or person photo

### File Format Recommendations
- JPEG or PNG format
- Resolution: At least 1024x1024 pixels
- File size: Under 5MB each

### Instructions for Session Organizers

Before the session, please add 3-5 sample images to this folder that participants can use for:
- Redesigning with AI tools
- Combining multiple images
- Experimenting with different styles and transformations

Participants are also encouraged to bring their own images!
