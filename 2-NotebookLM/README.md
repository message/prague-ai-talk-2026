# NotebookLM Practice

## Practice Activity

Explore Google's NotebookLM with Transcarent links for AI-powered note-taking and research.

### Task
Use NotebookLM to work with Transcarent links and create AI-generated summaries.

### Steps to Try

1. Access NotebookLM (https://notebooklm.google.com/)
2. Create a new notebook
3. Add Transcarent links as sources
4. Ask NotebookLM to:
   - Summarize the content
   - Generate insights
   - Create connections between sources
5. Explore the AI-generated audio overview feature

### Resources
- Transcarent links (to be provided during session)

### Expected Outcome
AI-powered summaries and insights from linked resources using NotebookLM's capabilities.

**Time Allocated**: Part of 20-minute hands-on practice session
